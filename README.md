 Sample Superstore - Power BI Mini Project
 
This project analyzes store performance, customer segments, shipments, and profitability to uncover valuable business insights.
 Project Overview
This mini project transforms raw retail data into an interactive multi-page dashboard using Power BI. It helps in tracking sales performance, evaluating profit margins, and understanding customer shipping behaviors.

 Data Modeling & Structure
 
The dataset is structured using a relational data model with the following tables:
 * SampleSuperstore: Contains core transactional details including Sales, Profit, Category, Sub-Category, City, State, Country, and Region.
 * Shipment Table: Manages shipping modes (Ship Mode) to analyze delivery performance.
 * Segment Table: Categorizes customers into distinct segments (Consumer, Corporate, Home Office).
 Dashboard Pages & Visualizations

Page 1: Overview & Key Metrics

 * KPI Cards: Displays total gross sales, profit, and key financial metrics.
 * Summary Visuals: High-level performance indicators for quick business evaluation.
 * 
Page 2: Customer & Geographic Analysis

 * City & Regional Charts: Visualizes sales and performance distribution across different locations.
 * Discounts & Profit Analysis: Explores the impact of discounts on overall profitability.
 * 
Page 3: Shipment, Segment & Profitability Breakdown

 * Pie/Donut Chart: Illustrates distribution across various ship modes.
 * Funnel Chart: Analyzes the flow of business metrics and process stages.
 * Bar Charts & Profit Margins: Detailed categorical comparison of sales and profit percentages.
   Tools & Technologies Used
 * Power BI Desktop: For data cleaning, modeling, and dashboard creation.
 * Power Query: For data transformation and preprocessing.
 * GitHub: For project repository hosting and version control.
